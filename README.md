## 📌 Project Overview
The **Inventory Management System (IMS)** is a modern desktop application built with Python to help businesses manage their core operations efficiently. From tracking stock levels to generating professional invoices, IMS centralizes all essential business tasks in a single, intuitive platform.

## 🚀 Key Features
*   **Dynamic Dashboard:** Visualized sales & stock analytics using Matplotlib.
*   **Product Management:** Real-time search, categorized inventory, and low-stock alerts.
*   **Advanced Sales System:** 
    *   Phone-number-based customer search.
    *   Auto-creation of new customer profiles during checkout.
    *   Smart product search suggestions.
*   **Supplier & Purchase Tracking:** Manage incoming stock and purchase history.
*   **Data Persistence:** Local storage using JSON for high portability and speed.
*   **Modern UI:** Dark-mode enabled interface using `CustomTkinter`.

## 🛠️ Technical Stack
*   **Language:** Python 3.x
*   **GUI:** CustomTkinter (Modernized Tkinter)
*   **Charts:** Matplotlib
*   **Storage:** JSON-based data management
*   **Dependencies:** Pillow (Image Handling), DarkDetect

## 📽️ Demo & Execution
1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/rumu5550/inventory-management-system.git
    cd inventory-management-system
    ```
2.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Run the Application:**
    ```bash
    python main.py
    ```
